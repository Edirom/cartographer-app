# Getting Started

To get started, just choose one of the following options:

- **Use it in your browser** — no installation required: simply open the app using the link provided by your institution, for instance <https://cartographer-app.zenmem.de/>.
- **Install it as a native application** — for Windows, macOS, Linux, or Android (e.g. for offline use), download the installer for your platform from the [releases page](https://github.com/Edirom/cartographer-app/releases) or use the download link provided by your institution.
