# Header

In the Cartographer App, the header contains a **title** and a **dropdown menu button**. Once you are logged in with GitHub, your **GitHub avatar** also appears in the header, and clicking the avatar shows the **Logout** option.

Clicking the menu reveals buttons for uploading or downloading MEI files, for loading IIIF image files from a server, and for logging in with GitHub. When logged in, the menu additionally contains an option to load files from GitHub.
Additionally, the header includes buttons to show the **Page Overview** and to toggle the **Measure List**.

---

## Menu Bar

Clicking the dropdown menu in the header opens the following options:

### Upload MEI File
Opens a file dialog where you can select and upload a local MEI file.

### Import IIIF Manifest
Opens a dialog to enter the URL of a IIIF manifest to load image data from a server.

### Import Local Image
Opens a file dialog to import images directly from a folder on your computer.

### Login with GitHub
Starts the GitHub sign-in process: you are redirected to GitHub to authorize the app and then returned to Cartographer. Once logged in, your GitHub avatar appears in the header.

### Load from GitHub
*Only visible when logged in with GitHub.* Opens a dialog to import MEI files and images directly from your GitHub repositories. After selecting a repository, you can choose the branch to load from; private repositories are supported.

### Download MEI File
Saves the current MEI file to your local machine.

### Show Page Overview
Displays a list of all pages with detailed information from an imported file.
It also contains a button to copy and paste a IIIF manifest (*Import Images button*).

### Toggle Measure List
Shows or hides the list of musical measures of the document next to the right toolbar.
